# OpenBKN

[English](README.md) | **中文**

**面向企业 AI 智能体的开源本体平台**

*An Open-Source Ontology Platform for Enterprise AI Agents*

OpenBKN 基于本体方法论描述企业中的对象、关系、规则、风险与行动，将分散在数据库、文档、系统、流程和专家经验中的知识，转化为 AI 智能体可理解、可执行、可治理、可追溯的**业务知识网络**（Business Knowledge Network）。

OpenBKN 提供从本体建模、数据连接、动态 Context 生成，到行动执行、安全治理和全链路追溯的完整能力。它不仅帮助智能体找到答案，更让智能体在明确的业务语义、证据依据与权限边界内，安全地参与真实业务。

我们的使命，是让每一家企业都能用好、用得起本体平台。我们相信，本体将成为连接企业 AI 智能体分析、决策与行动的基础设施；也期待与全球企业和开发者共同建设值得信赖的开源本体生态。

## 我们的开放理念

- **源码开放（Open Source）** —— 代码可审计、可扩展，可运行在企业自己的基础设施上。
- **架构开放（Open Architecture）** —— 服务模块化、接口有文档，模型、数据源与智能体均可自带接入。
- **生态开放（Open Ecosystem）** —— 与开发者、企业和合作伙伴共同建设。

## OpenBKN 由什么组成

| 项目 | 定位 |
| --- | --- |
| [**BKN Studio**](https://github.com/openbkn-ai/bkn-studio) | 开源本体建模与管理工作台，用于可视化构建企业本体和业务知识网络。 |
| [**BKN Foundry**](https://github.com/openbkn-ai/bkn-foundry) | 开源企业本体运行时，为本体提供数据连接、查询、Agent 上下文、安全执行、治理与追溯能力。 |
| [**BKN SDK**](https://github.com/openbkn-ai/bkn-sdk) | 面向开发者和 AI Agent 的 CLI、SDK 与 Agent Skill。 |
| [**BKN Samples**](https://github.com/openbkn-ai/bkn-samples) | 官方体验样例：示例知识网络、样例数据与导入工具。 |

## 为什么选择 OpenBKN

- **本体驱动，而非文本堆叠** —— 用业务对象、关系、规则、风险与行动表达真实业务语义。
- **面向 Agent 的动态上下文** —— 从本体按需生成高质量、带证据和约束的上下文。
- **从理解到行动** —— 将知识、工具和业务动作连接起来，让 Agent 不只回答问题，还能执行任务。
- **安全、可治理、可追溯** —— 将身份、权限、策略、风险控制和审计落到具体业务对象与行动上。
- **开源与可私有化部署** —— 代码可检查、能力可扩展，并可部署在企业自己的基础设施中。
