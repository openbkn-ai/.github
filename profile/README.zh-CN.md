# OpenBKN

[English](README.md) | **中文**

**面向企业 AI 智能体的开源本体平台**

*An Open-Source Ontology Platform for Enterprise AI Agents*

OpenBKN 基于本体方法论描述企业中的对象、关系、规则、风险与行动，将分散在数据库、文档、系统、流程和专家经验中的知识，转化为 AI 智能体可理解、可执行、可治理、可追溯的**业务知识网络**（Business Knowledge Network）。

OpenBKN 提供从本体建模、数据连接、动态 Context 生成，到行动执行、安全治理和全链路追溯的完整能力。它不仅帮助智能体找到答案，更让智能体在明确的业务语义、证据依据与权限边界内，安全地参与真实业务。

我们的使命，是让每一家企业都能用好、用得起本体平台。我们相信，本体将成为连接企业 AI 智能体分析、决策与行动的基础设施；也期待与全球企业和开发者共同建设值得信赖的开源本体生态。

## 为什么选择 OpenBKN

- **本体驱动的动态上下文** —— 基于本体按需提供高质量、带证据和约束的上下文。
- **从理解到行动** —— 将知识、工具和业务动作连接起来，让 Agent 不只回答问题，还能执行任务。
- **安全、可治理、可追溯** —— 将身份、权限、策略、风险控制和审计落到具体业务对象与行动上。
- **开源与可私有化部署** —— 代码可检查、能力可扩展，并可部署在企业自己的基础设施中。
