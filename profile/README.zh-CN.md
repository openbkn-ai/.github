# OpenBKN

[English](README.md) | **中文**

OpenBKN 是一个本体驱动的业务知识网络平台。它通过本体建模，将分散在文档、系统、流程、规则与专家经验中的数据与逻辑，转化为智能体可理解、可执行、可验证的业务知识网络，从而让智能体在真实业务环境中准确、安全、可靠地落地——不止生成答案，而是持续创造可执行、可追踪、可验证的业务价值。

OpenBKN 由 **BKN Studio** 和 **BKN Foundry** 组成：

- [**BKN Studio**](https://github.com/openbkn-ai/bkn-studio) —— 构建和管理业务知识网络
- [**BKN Foundry**](https://github.com/openbkn-ai/bkn-foundry) —— 运行和服务业务知识网络
